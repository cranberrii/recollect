# Quickstart: Recollect Bookmark Orchestrator

Welcome to the Recollect repository wiki. Recollect is an AI-powered bookmark manager with advanced semantic search, summarization, and categorization capabilities. This documentation is generated by OpenWiki and serves as your entrypoint to understanding, running, and evolving the project.

## Project Overview
- **Frontend**: Next.js 14+ App Router (apps/web)
- **Browser Extension**: Chrome extension (apps/extension)
- **Backend**: Python FastAPI (backend)
- **Database**: Supabase (PostgreSQL + pgvector)
- **AI**: OpenRouter (OpenAI-compatible API)


### Repo Structure

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/cranberrii/recollect.git
   cd recollect
   ```
2. Install dependencies:
   - Node.js:
     ```bash
     npm install
     ```
   - Python:
     ```bash
     cd backend
     uv venv
     source .venv/bin/activate  # On Windows: .venv\Scripts\activate
     uv pip install -e ".[dev]"
     ```
3. Set up environment variables:
   - Copy and edit `.env.example` in `backend/`
4. Set up Supabase:
   - Run migrations:
     ```bash
     supabase login
     supabase link
     supabase db push
     ```

## Running & Developing

- **Run all services:** `npm run dev`
- **Frontend only:** `cd apps/web && npm run dev -- --turbo`
- **Backend only:** `cd backend && uv run uvicorn app.main:app --reload`
- **Extension build:** `npm run dev:extension` (then load unpacked from `apps/extension/dist`)

## Building
- **Build all:** `npm run build`
- **Build web only:** `npm run build:web`
- **Build extension only:** `npm run build:extension`

## Testing & Linting
- **Python backend tests:** `cd backend && pytest tests/`
- **Frontend lint:** `npm run lint`
- **Backend lint:** `cd backend && ruff check app/`
